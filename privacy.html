KeptClip Privacy Policy

Last updated: November 5, 2026

The short version: everything you copy stays on your Mac. KeptClip has no servers, no analytics, and no tracking. We cannot see your data because it is never sent anywhere.

What KeptClip Stores

KeptClip is a clipboard history manager. To work, it must store what you copy — text, images, and file references. This data is stored only in the app's local storage on your Mac (in the app container under ~/Library/Application Support).

When you preview a text clip with Quick Look, KeptClip writes that text to a temporary file in the system temporary directory so macOS can render the preview. The file is replaced each time you preview another clip and is never copied anywhere else.

What We Collect

Nothing. KeptClip:

  • Does not upload any data to any server
  • Makes no network connections of its own — the only network activity related to the app is App Store purchase handling, performed by Apple's system frameworks (StoreKit)
  • Does not include analytics, advertising, or third-party SDKs
  • Does not collect, transmit, or share personal information
  • Performs all processing — including sensitive-content detection — entirely on your device
  • Recognizes text inside screenshots locally with Apple's Vision framework (OCR) — recognized text never leaves your device

Data Retention

  • Your history has no item limit (pinned clips are always kept).
  • Image storage is capped locally (2 GB, oldest first) on all versions. Pro adds multi-select merge paste and App Lock.
  • You can delete individual clips at any time, or clear all history in Settings → Storage.

Deleting Your Data

  • Individual items: hover a clip and click ✕, or press ⌘⌫, or right-click → Delete.
  • Everything: Settings → Storage → Clear history (pinned clips are kept), then delete them manually if desired.
  • Complete removal: delete the KeptClip app — all data lives inside the app container and is removed with it.

Sensitive-Content Protection

KeptClip automatically detects content that looks like credit card numbers, private keys, API tokens, or national ID numbers, and refuses to store it. This detection runs entirely on your Mac using pattern matching. Nothing about detected content is transmitted or logged anywhere.

Purchases

Pro is a one-time purchase processed entirely by Apple through the App Store. We never receive your name, payment details, or any identifying information. See Apple's privacy policy for how Apple handles purchase data.

Permissions

KeptClip does not require Accessibility, Input Monitoring, Full Disk Access, or Screen Recording permissions. It reads the system clipboard the same way pressing ⌘V does.

App Lock and Touch ID

App Lock (a Pro feature) asks macOS to authenticate you with Touch ID through Apple's LocalAuthentication framework. KeptClip never receives, reads, or stores fingerprint data — macOS only tells the app whether authentication succeeded. The on/off preference for App Lock is stored locally on your Mac.

Changes to This Policy

If this policy changes, the updated version will be published on this page.

KeptClip 隐私政策

更新日期：2026 年 11 月 5 日

一句话版本：你复制的所有内容都只保存在你的 Mac 上。KeptClip 没有服务器、没有统计 SDK、没有任何追踪——数据从不离开你的设备，我们也无从看到。

KeptClip 存储什么

KeptClip 是一款剪贴板历史管理工具。为实现功能，它需要保存你复制的内容——文本、图片和文件引用。这些数据仅存储在你 Mac 上的应用本地目录中（位于 ~/Library/Application Support 的应用容器内）。

使用快速预览（Quick Look）查看文本条目时，KeptClip 会将该文本写入系统临时目录下的临时文件，供 macOS 渲染预览。每次预览新条目都会替换该文件，内容不会被复制到任何其他位置。

我们收集什么

什么都不收集。KeptClip：

  • 不向任何服务器上传数据
  • 自身不发起任何网络连接——与本应用相关的唯一网络活动是 App Store 购买处理，由 Apple 的系统框架（StoreKit）完成
  • 不含统计分析、广告和任何第三方 SDK
  • 不收集、传输或共享个人信息
  • 所有处理（包括敏感内容检测）完全在你的设备上完成
  • 截图文字识别（OCR）由 Apple Vision 框架在本地完成——识别结果不会离开你的设备

数据保留

  • 历史条数不设上限；可选的保留策略（7/30/90 天/永久）自动清理过期条目，固定置顶的条目不受影响。
  • 所有版本的图片存储均为本地配额（2 GB，超限优先淘汰最旧）。Pro 增加多选合并粘贴与应用锁。
  • 你可以随时删除单条内容，或在 设置 → 存储 中清空全部历史。

如何删除你的数据

  • 删除单条：悬停条目点击 ✕、按 ⌘⌫，或右键菜单 → 删除。
  • 清空历史：设置 → 存储 → 清空历史（固定条目保留，可再手动删除）。
  • 彻底移除：删除 KeptClip 应用——所有数据都在应用容器内，会随之一起删除。

敏感内容保护

KeptClip 会自动检测疑似银行卡号、私钥、API Token、身份证号的内容并拒绝保存。该检测完全通过本机模式匹配完成，被检测内容的任何信息都不会被传输或记录到任何地方。

关于购买

Pro 为一次性买断，购买流程完全由 Apple 通过 App Store 处理。我们不会收到你的姓名、支付信息或任何可识别身份的信息。Apple 如何处理购买数据请参阅 Apple 的隐私政策。

关于权限

KeptClip 不需要辅助功能、输入监控、完全磁盘访问或屏幕录制权限。它读取系统剪贴板的方式与按下 ⌘V 粘贴相同。

应用锁与 Touch ID

应用锁（Pro 功能）通过 Apple 的 LocalAuthentication 框架请求 macOS 进行 Touch ID 验证。KeptClip 不会接收、读取或存储任何指纹数据——macOS 只告诉应用验证是否通过。应用锁的开关状态仅保存在你的 Mac 本地。

政策变更

如本政策发生变更，更新版本将在本页面发布。

KeptClip プライバシーポリシー

最終更新日：2026年11月5日

要点：コピーした内容はすべてあなたのMacの中だけに保存されます。KeptClipにサーバーはなく、アナリティクスもトラッキングもありません。データはどこにも送信されないため、開発者が見ることもできません。

KeptClipが保存するもの

KeptClipはクリップボード履歴管理ツールです。機能のために、コピーした内容（テキスト・画像・ファイル参照）を保存する必要があります。このデータはあなたのMac上のアプリのローカルストレージにのみ保存されます（~/Library/Application Support のアプリコンテナ内）。

テキスト項目をQuick Lookでプレビューする際、KeptClipはmacOSがプレビューを描画できるよう、そのテキストをシステムの一時ディレクトリ内の一時ファイルに書き出します。このファイルは別の項目をプレビューするたびに置き換えられ、他の場所にコピーされることはありません。

収集するもの

何も収集しません。KeptClipは：

  • データをサーバーにアップロードしません
  • アプリ自身はネットワーク接続を行いません。アプリに関連するネットワーク通信は、Appleのシステムフレームワーク（StoreKit）が行うApp Storeの購入処理のみです
  • アナリティクス・広告・サードパーティSDKを含みません
  • 個人情報を収集・送信・共有しません
  • センシティブコンテンツの検出を含むすべての処理をデバイス上で完結させます
  • スクリーンショット内のテキスト認識（OCR）は Apple Vision フレームワークによりローカルで実行され、認識結果がデバイスの外に出ることはありません

データの保持

  • 履歴の件数に上限はありません（ピン留めした項目は常に保持）。
  • 画像ストレージは全バージョン共通でローカル上限があります（2 GB、古いものから削除）。Pro では複数選択のまとめコピーと App Lock を追加。
  • 項目はいつでも個別に削除でき、設定 → ストレージから全履歴を消去できます。

データの削除

  • 個別の項目：項目にカーソルを合わせて ✕ をクリック、⌘⌫ を押す、または右クリック → 削除。
  • すべて：設定 → ストレージ → 履歴を消去（ピン留めは保持されます）。
  • 完全な削除：KeptClipアプリを削除 — すべてのデータはアプリコンテナ内にあり、一緒に削除されます。

センシティブ情報の保護

KeptClipは、クレジットカード番号、秘密鍵、APIトークン、身分証明書番号と思われる内容を自動的に検出し、保存しません。この検出はあなたのMac上でパターンマッチングによって完全に実行され、検出された内容に関する情報が送信されたり記録されたりすることは一切ありません。

購入について

Proは買い切りで、購入はすべてAppleがApp Storeを通じて処理します。開発者があなたの氏名、支払い情報、識別情報を受け取ることはありません。購入データのAppleでの扱いについては、Appleのプライバシーポリシーをご覧ください。

権限について

KeptClipはアクセシビリティ、入力監視、フルディスクアクセス、画面収録の権限を必要としません。システムのクリップボードを読み取る方法は、⌘Vを押すのと同じです。

アプリロックとTouch ID

アプリロック（Pro機能）は、AppleのLocalAuthenticationフレームワークを通じてmacOSにTouch ID認証を要求します。KeptClipが指紋データを受け取ったり読み取ったり保存したりすることはありません。macOSは認証に成功したかどうかだけをアプリに伝えます。アプリロックのオン／オフ設定はお使いのMac内にのみ保存されます。

ポリシーの変更

本ポリシーを変更する場合は、更新版をこのページに公開します。

KeptClip 개인정보 처리방침

최종 업데이트: 2026년 11월 5일

핵심 요약: 복사한 모든 내용은 당신의 Mac에만 저장됩니다. KeptClip에는 서버도, 분석 도구도, 추적도 없습니다. 데이터는 어디로도 전송되지 않으므로 개발자가 볼 수도 없습니다.

KeptClip이 저장하는 것

KeptClip은 클립보드 기록 관리 도구입니다. 동작을 위해 복사한 내용(텍스트, 이미지, 파일 참조)을 저장해야 합니다. 이 데이터는 당신의 Mac에 있는 앱의 로컬 저장소에만 저장됩니다(~/Library/Application Support의 앱 컨테이너 내부).

텍스트 항목을 Quick Look으로 미리 볼 때, KeptClip은 macOS가 미리보기를 렌더링할 수 있도록 해당 텍스트를 시스템 임시 디렉터리의 임시 파일에 기록합니다. 이 파일은 다른 항목을 미리 볼 때마다 교체되며 다른 곳으로 복사되지 않습니다.

수집하는 것

아무것도 수집하지 않습니다. KeptClip은:

  • 어떤 데이터도 서버로 업로드하지 않습니다
  • 앱 자체는 네트워크 연결을 만들지 않습니다. 앱과 관련된 유일한 네트워크 활동은 Apple의 시스템 프레임워크(StoreKit)가 수행하는 App Store 구매 처리입니다
  • 분석, 광고, 서드파티 SDK를 포함하지 않습니다
  • 개인정보를 수집·전송·공유하지 않습니다
  • 민감 콘텐츠 감지를 포함한 모든 처리를 기기에서 완료합니다
  • 스크린샷 속 텍스트 인식(OCR)은 Apple Vision 프레임워크로 기기에서 로컬로 수행되며, 인식 결과는 기기를 벗어나지 않습니다

데이터 보관

  • 기록 개수에 상한이 없습니다(고정된 항목은 항상 유지).
  • 이미지 저장은 모든 버전에서 로컬 한도가 있습니다(2 GB, 오래된 것부터 삭제). Pro는 다중 선택 병합 붙여넣기와 앱 잠금을 추가합니다.
  • 항목은 언제든 개별 삭제할 수 있고, 설정 → 저장 공간에서 전체 기록을 지울 수 있습니다.

데이터 삭제

  • 개별 항목: 항목에 마우스를 올리고 ✕ 클릭, ⌘⌫ 누르기, 또는 오른쪽 클릭 → 삭제.
  • 전체: 설정 → 저장 공간 → 기록 지우기(고정 항목은 유지).
  • 완전 삭제: KeptClip 앱 삭제 — 모든 데이터는 앱 컨테이너 안에 있으며 함께 삭제됩니다.

민감 정보 보호

KeptClip은 신용카드 번호, 개인 키, API 토큰, 신분증 번호로 보이는 내용을 자동으로 감지하여 저장하지 않습니다. 이 감지는 당신의 Mac에서 패턴 매칭으로만 실행되며, 감지된 내용에 대한 정보는 어디에도 전송되거나 기록되지 않습니다.

구매

Pro는 일회성 구매이며, 구매는 전부 Apple이 App Store를 통해 처리합니다. 개발자가 당신의 이름, 결제 정보, 식별 정보를 받지 못합니다. 구매 데이터의 Apple 처리 방식은 Apple의 개인정보 처리방침을 참고하세요.

권한

KeptClip은 손쉬운 사용, 입력 모니터링, 전체 디스크 접근, 화면 기록 권한이 필요 없습니다. 시스템 클립보드를 읽는 방식은 ⌘V를 누르는 것과 같습니다.

앱 잠금과 Touch ID

앱 잠금(Pro 기능)은 Apple의 LocalAuthentication 프레임워크를 통해 macOS에 Touch ID 인증을 요청합니다. KeptClip은 지문 데이터를 받거나 읽거나 저장하지 않습니다. macOS는 인증 성공 여부만 앱에 알려줍니다. 앱 잠금 설정은 사용자의 Mac에만 저장됩니다.
