클립보드가 단축키 하나로

복사한 모든 것 — 텍스트, 링크, 코드, 이미지, 파일 — 을 검색 가능한 기록으로. 데이터는 당신의 Mac 안에 저장됩니다.

KeptClip은 macOS 14 이상을 위한 경량 로컬 클립보드 기록 관리 도구입니다(약 5.5MB). 접근성·입력 모니터링 권한이 필요 없고, 카드 번호와 API 토큰을 기기 내에서 자동 차단하며, 스크린샷 속 글자도 기기 내 OCR로 검색합니다. 무료 버전은 기록 한도 없이 보관되고 ⌘⇧V로 검색합니다. Pro는 ¥68 / $9.99 일회성 구매로 다중 선택 병합 붙여넣기와 앱 잠금을 추가합니다. 데이터는 Mac 안에 저장됩니다.

자주 묻는 질문

macOS 동작, 개인정보, 가격에 대한 짧은 답변.

KeptClip은 왜 macOS 접근성 권한과 입력 모니터링이 필요 없나요?

KeptClip은 메뉴 막대 패널에서 시스템 클립보드를 읽습니다. 키 입력을 시뮬레이션하거나 다른 앱을 감시하지 않아 접근성·입력 모니터링·화면 녹화 권한을 요청하지 않습니다. 권한 부여가 제한된 기업용 Mac에 적합합니다.

API 토큰, 개인 키, 카드 번호는 어떻게 자동 차단되나요?

감지는 모두 Mac에서 오프라인으로 실행됩니다. 기록에 저장되기 전에 카드 번호·개인 키·API 토큰 패턴과 대조하여 해당하면 저장을 거부하고 메뉴 막대 아이콘을 잠시 방패로 표시합니다. 업로드는 전혀 없습니다.

무료 버전과 ¥68 / $9.99 일회성 구매 Pro의 차이는 무엇인가요?

무료 버전은 기록 개수 제한이 없고 전체 즉시 검색(기기 내 OCR로 인식한 스크린샷 글자 포함), 일반 텍스트 복사, 키보드 워크플로우 전체, 인라인 및 Space 미리보기, 7/30/90일 보관 설정이 포함됩니다. Pro는 ⌘-클릭 다중 선택 병합 붙여넣기와 Touch ID／암호 앱 잠금만 ¥68 / $9.99 한 번으로 추가합니다. 구독도 계정도 없습니다.

어떤 클립보드 형식과 macOS 버전을 지원하나요?

텍스트, 링크, 코드, 이미지, 파일을 지원하며 스크린샷 속 글자도 기기 내 OCR로 검색할 수 있습니다. macOS 14.0 이상 필요, Apple Silicon과 Intel 모두 지원. 인터페이스는 영어·简体中文·日本語·한국어 4개 언어입니다.

자동으로 붙여넣어주나요?

아니요 — 의도된 설계입니다. Mac App Store는 키 입력 시뮬레이션을 금지합니다(가이드라인 2.4.5). KeptClip은 선택한 항목을 클립보드에 복사하고 알려주며, ⌘V는 직접 누릅니다. macOS 기본 워크플로우와 동일합니다.

데이터는 어디에 저장되나요?

당신의 Mac 앱 샌드박스 컨테이너 안에만 저장됩니다. 업로드 없음, 구매(StoreKit) 외 통신 없음.

시스템 요구사항은?

macOS 14(Sonoma) 이상. Apple Silicon과 Intel 모두 지원합니다.

지원 언어는?

영어·简体中文·일본어·한국어 — 메뉴와 단축키 연동을 포함한 전체 인터페이스.

Pro는 어떻게 구매하나요?

앱 내 일회성 구매: 패널을 열고 톱니바퀴 아이콘 → KeptClip Pro 섹션. 구독도 계정도 없으며, 무료 버전은 항상 완전하게 사용할 수 있습니다.
